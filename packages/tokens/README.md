# @up201905892/tokens

Design tokens of the design system: CSS variables for the light and dark themes, plus a typed JS object.

## Installation

```
pnpm add @up201905892/tokens
```

## Usage

```css
@import '@up201905892/tokens/tokens.css';
@import '@up201905892/tokens/themes.css';
```

```ts
import { tokens } from '@up201905892/tokens';
```
