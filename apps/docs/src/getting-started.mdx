# Getting started

## What is this library

`@up201905892/ui` is an accessible React component library with light and dark themes. Every component works with the keyboard only, and all colours, spacing and radii come from design tokens.

## Requirements

- React 18 or 19 (`react` and `react-dom` are peer dependencies).
- Node.js 22 or later for the tooling of this repository; the published packages run in any bundler that supports ES modules or CommonJS.

## Installation

<Source
  language="bash"

  code={`pnpm add @up201905892/ui @up201905892/icons
